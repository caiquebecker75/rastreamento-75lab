# Rastreamento de PDV · 75 LAB

Apresentação comercial interativa das tecnologias de rastreamento de materiais de comunicação da 75 LAB:

* **One Shot**: rastreio estático (QR, GPS, foto da fachada, positivação)
* **OnTiming**: rastreio ao vivo (transporte, armazenagem, alerta de saída, inventário)

10 telas: capa, o que fazemos, One Shot (como funciona, indicadores, investimento), OnTiming (como funciona, indicadores, planos), simulador comparativo e próximo passo. Arquivos: `index.html`, `style.css`, `script.js`, `img/`.

Navegação: setas ou espaço, `M` abre o índice, `Home` e `End`, swipe no celular. Link direto para uma tela: `#simulador`, `#precos`, `#dados`.

Os dados das telas de indicadores são ilustrativos.
